    Les règles, en quelques mots +

    Trouvez les 4 couleurs dans le bon ordre en 10 essais. Une couleur peut apparaître plusieurs fois.

    Bien placée : bonne couleur, bonne position.
    Mal placée : couleur présente, autre position.

    Chaque occurrence compte une seule fois, en commençant par les positions exactes. Les nombres ne désignent aucun pion précis.

    Vous pouvez modifier les quatre pions avant validation. Le code reste caché, même à la fin.

    Installer et jouer hors ligne +

    Sur iPhone, ouvrez ce jeu dans Safari, puis touchez Partager → Sur l’écran d’accueil → Ajouter. Si l’option « Ouvrir comme app web » apparaît, activez-la.

    Ouvrez ensuite l’icône Code secret avec Internet et attendez la confirmation ci-dessous avant de jouer hors ligne.

    Préparation du jeu hors ligne…

    Une mise à jour est prête. Pour l’utiliser, fermez toutes les fenêtres du jeu, puis rouvrez-le avec Internet. Votre partie actuelle peut continuer.

    Recharger ou fermer le jeu recommence la partie. Le navigateur peut effacer les fichiers hors ligne : dans ce cas, ouvrez à nouveau le jeu avec Internet.
